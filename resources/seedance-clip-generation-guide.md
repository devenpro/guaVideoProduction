## 2. Step 0 — Audio Direction Selection

At the start of every campaign (before Stage 1 analysis), the app must ask the user which audio direction the campaign will follow. This choice governs script length, VFX text density, Seedance prompt construction, and post-production requirements for every video in the campaign.

### The User-Facing Question

> **"How should audio work in this campaign?"**
> Pick one of the three options below. You can override per-video later, but this is the default.

### Option A — Voice + Ambient (Default)

**What it is:** ElevenLabs voiceover is the foreground audio. Seedance generates ambient environmental sound natively. No music.

**What the user gets:**
- Clean, voice-led ads
- Every clip has a scripted voiceover fed to Seedance
- Ambient comes from the visual scene (birds, water, traffic, footsteps)
- No post-production music work

**Best for:** Presenter Walkthrough, Amenity Spotlight, Interior Tour, Location Advantage, Price/Offer Reveal, Developer Trust — i.e. most video types.

**ElevenLabs settings baseline:**
- Stability: 0.55–0.65
- Similarity boost: 0.70–0.80
- Style: 0.30–0.40
- Indian English accent matched to the project region

**Audio layering for final stitched video:**
```
Voice (0 dB — foreground)
   └─ Ambient (−14 to −16 dB — generated by Seedance)
```

---

### Option B — Voice + Ambient + Post-Production Music

**What it is:** Same as Option A, plus a background music bed added during final stitching. Music is **never fed into Seedance** — it is layered over the stitched video in an editor.

**What the user gets:**
- Cinematic cohesion across stitched clips
- A music bed that connects the 4–6 clips of a Hero Film into one flowing piece
- A separate Suno.com (or equivalent) music generation prompt produced in Stage 4

**Best for:** Project Hero Film (almost always benefits from music). Rarely used for other video types.

**Suno prompt must define:**
- Genre and BPM (e.g., modern ambient electronic, 80–100 BPM)
- Mood progression (rise → peak → settle)
- Instrumentation (pads, piano, strings, light percussion)
- Duration (matches assembled video length)
- Ending style (natural fade, not abrupt cutoff)
- Character limit: under 500 characters

**Music style recommendations by project type:**

| Project Type | Recommended Style |
|---|---|
| Premium apartment | Modern ambient electronic, subtle pads, soft rhythm — 80–100 BPM |
| Luxury apartment / villa | Cinematic orchestral undertone, piano, strings — 70–90 BPM |
| Plotted development | Acoustic warmth, guitar, light percussion — 90–110 BPM |
| Youth / starter homes | Contemporary indie, clean, bright, forward-moving — 100–120 BPM |

**Audio layering for final stitched video:**
```
Voice (0 dB — foreground)
   └─ Ambient (−14 to −16 dB — generated by Seedance)
       └─ Music (−18 dB or lower — added in post)
```

**Hard rule:** Music is mixed at −18 dB or lower relative to voice. Music is the lowest layer, always. Voice > Ambient > Music.

---

### Option C — Ambient Only (No Voice)

**What it is:** No ElevenLabs voiceover. The clip is carried by ambient sound plus VFX text overlays. Text replaces narration.

**What the user gets:**
- Purely visual storytelling
- Sound-off viewing works natively (most Meta viewers watch muted anyway)
- Maximum VFX text density — text overlays carry all information

**Best for:** Lifestyle Moment videos (single-clip mood pieces). Occasional retargeting pieces.

**Implications for the clip prompt:**
- No audio file is fed to Seedance
- `AUDIO HANDLING` section instructs Seedance to generate ambient only
- VFX text entries are **timer-based**, not dialogue-synced
- Final hold carries the project name or one-line tagline as a kicker

**Audio layering for final stitched video:**
```
Ambient (0 dB — foreground, generated by Seedance)
   └─ Music (−10 to −14 dB — added in post, optional)
```

---

### How the App Uses the Selection

| Selection | Affects |
|---|---|
| **Option A** | Standard voice script per clip, standard Seedance prompt with audio input |
| **Option B** | Same as A + music prompt generated in Stage 4 per video, post-production music mix note |
| **Option C** | No voice script, Seedance prompt omits audio file input, VFX text timer-based instead of dialogue-synced, scripts become text-only visual plans |

The app stores the selection and injects the corresponding audio-handling block into every Seedance prompt it generates.

## 3. Seedance 2.0 — Capabilities, Inputs, Outputs

### What Seedance 2.0 Does

Seedance 2.0 is a multi-input AI video generation model. Given three types of input plus a text prompt, it produces a single coherent video clip with camera movement, character animation, scene transitions, ambient audio, and lip sync.

### The Three Input Types

**1. Character Reference Image (optional per clip)**
- A single reference image of the presenter/character
- Seedance uses it to maintain appearance (face, hair, build, wardrobe) across the clip
- The prompt reinforces key features (wardrobe colour, accessories, distinguishing features) in text — the image alone is not always enough
- If the clip has no character: simply don't provide a reference image, and state "No character in this clip."

**2. Environment Images (1–3 per clip)**
- Scene/location images defining what each space looks like
- Can be brochure renders, uploaded project photos, or AI-generated (Imagen 3 / Seedream)
- Multiple images allow scene changes within a single clip
- Each image must be clean — **no text overlays baked into the image** (VFX text is instructed in the prompt)
- Format: 9:16 vertical, 1080×1920

**3. Audio File (optional per clip, based on Step 0 selection)**
- Pre-generated ElevenLabs voiceover, per clip
- Mono, 44.1/48 kHz, peak normalized to −1 dBFS, 0.3s silence padding each end
- Duration must be shorter than clip duration (leaves 1.0–1.5s visual buffer at end)
- Seedance uses it as the primary voice track and syncs character lip movement to it

### What Seedance Generates Natively

From the three inputs + the prompt, Seedance produces:
- Video with character composited into the environment(s) — 1080×1920, 24fps
- Character animation: movement, gestures, facial expressions, lip sync
- Camera movement as instructed (dolly, pan, crane, orbit, static hold, glide-through)
- Scene transitions between environment images at specified timestamps
- **Ambient audio** matching the visual scene (birds, water, footsteps, traffic, interior reverb)
- The provided audio file as the foreground voice track, layered over ambient

### What Seedance Must NEVER Generate

- Additional voice, dialogue, or narration beyond the provided audio file
- Background music (music is post-production only)
- Text overlays not listed in the prompt's VFX Text Instructions
- People, objects, or elements not described in the scene instructions

These prohibitions are enforced by explicit `DO NOT` lines in the prompt.

### Clip Duration Rules

- Sweet spot: **8–10 seconds per clip**
- Maximum: 15 seconds (occasional, for clips needing extended movement or held scene)
- Scene count: 1–3 environment changes per clip
- Per-scene duration: 2.5–5 seconds each in 8–10 second clips
- Scene changes should land on natural pauses in the voiceover — never mid-word

```
│ 3. AUDIO FILE (if Option A or B)                               │
│    □ Voiceover generated via ElevenLabs                        │
│    □ Duration shorter than clip duration (see buffer table)    │

│    □ Pronunciation verified for proper nouns                   │
│                                                                 │

│    □ Camera movement summary (from Stage 3)                    │
└────────────────────────────────────────────────────────────────┘
```

### Audio Duration vs Clip Duration Buffer

| Clip Duration | Max Audio Duration | Visual Buffer at End |
|---|---|---|
| 8 seconds | 6.5–7.0 seconds | 1.0–1.5s |
| 10 seconds | 8.5–9.0 seconds | 1.0–1.5s |
| 12 seconds | 10.5–11.0 seconds | 1.0–1.5s |
| 15 seconds | 13.0–13.5 seconds | 1.5–2.0s |

The buffer is the final hold — the time after the voice ends where all VFX text is visible simultaneously and the camera settles.

```
[project-code]-[video-type]-clip[N]-env-scene[N].png
[project-code]-[video-type]-clip[N]-seedance-prompt.txt
```

## 5. The Seedance Prompt Structure

Every Seedance prompt has **7 mandatory sections** in this exact order:

```
┌─────────────────────────────────────────────────────────────┐
│ 1. HEADER                                                    │
│    Clip number, title, video type, format, duration, scene  │
│    count, character presence, audio presence                 │
├─────────────────────────────────────────────────────────────┤
│ 2. INPUT DECLARATION                                         │
│    Labels every input (character, env images, audio)        │
│    Declares what each input is and where it's used          │
├─────────────────────────────────────────────────────────────┤
│ 3. AUDIO HANDLING                                            │
│    How to treat provided audio + what ambient to generate   │
│    Explicit prohibitions (no extra voice, no music)         │
├─────────────────────────────────────────────────────────────┤
│ 4. SCENE-BY-SCENE INSTRUCTIONS                               │
│    Timestamped blocks — one per scene                        │
│    Camera, character action, ambient per scene              │
│    Explicit "Hard cut at X.Xs" between scenes               │
├─────────────────────────────────────────────────────────────┤
│ 5. VFX TEXT OVERLAY INSTRUCTIONS                             │
│    Every text element with exact string, style, position,   │
│    entry time, animation, scene, persistence                │
│    Locked from Stage 3 — no new text added here             │
├─────────────────────────────────────────────────────────────┤
│ 6. FINAL HOLD                                                │
│    What the last 1.0–1.5s looks like                         │
│    All text visible, camera settled, character in end state │
├─────────────────────────────────────────────────────────────┤
│ 7. QUALITY DIRECTIVES                                        │
│    Visual quality mandates                                   │
│    Character consistency reinforcements                     │
│    Camera constraints, scene change rules, audio rules      │
│    DO NOT prohibitions                                       │
└─────────────────────────────────────────────────────────────┘
```

### Prompt Length Targets

| Complexity | Target Word Count |
|---|---|
| Single-scene, no character | 400–600 words |
| Single-scene, with character | 500–750 words |
| Two-scene, no character | 600–900 words |
| Two-scene, with character | 750–1,100 words |
| Three-scene, with character | 900–1,400 words |

If over 1,500 words: trim redundancy, not structure. Never cut: input declarations, audio handling, scene timestamps, VFX text specs, key character feature reinforcements, or DO NOT lines.

## 6. The Complete Prompt Template

```
================================================================
CLIP [N] — [CLIP TITLE]
Video: [Video type name]
Tool: Seedance 2.0
Format: 9:16 vertical, 1080×1920, 24fps
Duration: [X] seconds
Scenes: [X] (using [X] environment images)
Character: [Present — P-XXX / Not present]
Audio: [Provided — ElevenLabs, X.X seconds / None — ambient only]
================================================================

================================================================
INPUT DECLARATION
================================================================

CHARACTER REFERENCE IMAGE: [if applicable — else omit entire block]
  This is the presenter — [brief description: age, ethnicity, build,
  wardrobe, hair]. Maintain her exact appearance throughout the clip.
  Key features to preserve:
  - [Feature 1 — e.g., "Cobalt blue blazer, fully open, never buttoned"]
  - [Feature 2 — e.g., "Long dark brown hair in loose waves"]
  - [Feature 3 — e.g., "Gold pendant necklace, small hoop earrings"]
  - [Feature 4 — if applicable]
  She appears in: [Scene 1 and Scene 2 / all scenes / Scene 2 only].

ENVIRONMENT IMAGE 1 — [SCENE NAME]:
  [One-line description — e.g., "Project entrance with landscaped

  Used for: Scene 1 (0.0s–[X.X]s)

ENVIRONMENT IMAGE 2 — [SCENE NAME]:
  [One-line description]
  Used for: Scene 2 ([X.X]s–[Y.Y]s)

ENVIRONMENT IMAGE 3 — [SCENE NAME]: [if applicable]
  [One-line description]
  Used for: Scene 3 ([Y.Y]s–[Z.Z]s)

AUDIO FILE:
  Pre-recorded voiceover, [X.X] seconds duration.
  [If character speaks:] This is the primary voice track. Sync the
  character's lip movement to this audio.
  [If no character:] No lip sync required — voiceover only.
  Generate ambient environmental sound matching each scene.

[If Option C — Ambient only, replace AUDIO FILE block with:]
AUDIO:
  No voice audio file provided. This clip is ambient-only.
  Generate environmental sound matching each scene visually.
  No voice, no narration, no dialogue of any kind.

================================================================
AUDIO HANDLING
================================================================

PRIMARY AUDIO: [Use the provided audio file as the voice track for

[If character speaks:]

  - Scene 1: [X.Xs–Y.Ys]
  - Scene 2: [X.Xs–Y.Ys]

  surface movement, contained open-air acoustic, softer breeze. The
  sound narrows relative to the open garden."]

AMBIENT LEVEL: Ambient sits beneath the voice — felt, not heard. The

DO NOT generate any additional voice, narration, dialogue, or speech
beyond the provided audio.
DO NOT generate background music.

================================================================
SCENE-BY-SCENE INSTRUCTIONS
================================================================

  Environment: Use Environment Image 1
  Camera:
    Start: [What the viewer sees at 0.0s — specific framing]
    Movement: [Type — e.g., "Slow dolly-in toward entrance"]
    Speed: [Rate — e.g., "Barely perceptible, 5–8% of frame depth"]

  Character: [If present]
    Position: [Where in frame — left/centre/right third]
    Action: [Natural movement — e.g., "Walking forward slowly"]
    Gesture: [Specific gesture tied to timestamp]

SCENE 2 ([X.X]s–[Y.Y]s) — [SCENE NAME]
  Environment: Use Environment Image 2
  Camera:
    Start: [Starting frame — independent of Scene 1's end frame]
    Movement: [Type]
    Speed: [Rate]
    End: [End frame]
  Character: [Position, action — or "Not visible in this scene"]
  Ambient: [Different acoustic from Scene 1]

[--- TRANSITION: Hard cut at [Y.Y]s --- (if Scene 3 exists)]

[SCENE 3 block if applicable — same format]

================================================================
VFX TEXT OVERLAY INSTRUCTIONS
================================================================

  String: "[EXACT TEXT — ALL CAPS IF CHIP/KICKER]"
  Style: [Frosted pill chip / Floating data card / Bottom kicker /
          Location label / Brand bar / Offer badge / Split chips]

                  no dialogue]

  Scene: [Which scene number this enters in]
  Persistence: [Visible until end of clip / Exits at X.Xs]

TEXT 2:
  [Same fields]

TEXT 3:
  [Same fields]

  At [X.X]s to end of clip, the following text elements are ALL

  - [Text 1 string]
  - [Text 2 string]
  - [Text 3 string]
  This is the final visual state the viewer holds on.

================================================================
FINAL HOLD ([X.X]s–[clip end])
================================================================

Camera: [Static hold / final settling position]
Character: [Final position and expression — or "Not visible"]
Environment: [Which environment image is showing]
Text visible: [List all text elements on screen]
Ambient: [Final ambient state — typically the quietest moment]

This is the frame the viewer sees longest. It must be clean,
composed, and carry the complete visual message of the clip.

================================================================
QUALITY DIRECTIVES
================================================================

VISUAL QUALITY:
- Photorealistic, editorial quality throughout
- No AI skin softening on character
- No AI artifacts — no warped hands, extra fingers, distorted
  architecture
- Straight architectural lines, correct perspective
- Lighting consistent within each scene — direction does not shift

CHARACTER CONSISTENCY: [if character present]
- Character must match the reference image exactly
- [Key feature reinforcement 1 — e.g., "Blazer is cobalt blue, fully
  open, NEVER buttoned"]
- [Key feature reinforcement 2 — e.g., "Gold pendant necklace visible
  at all times"]
- [Key feature reinforcement 3 if applicable]
- Skin tone remains consistent across all scenes
- Character proportions remain natural

CAMERA:
- All camera movement is slow and deliberate — never fast or jerky
- [Specific speed constraint for this clip]
- No sudden acceleration or deceleration

SCENE CHANGES:
- Hard cuts only — no dissolves, wipes, fades, or blending
- Each scene starts cleanly with its own environment image
- Character position may change between scenes (new scene justifies
  new position)

AUDIO:
- Use ONLY the provided audio file for voice — generate no additional
  speech
- Generate ambient environmental sound matching each scene
- No background music generation
- Ambient level sits well below the voice

EXTERIOR LIGHTING: [if applicable]
- Building architectural lights ON — warm amber glow from windows
- Two light sources minimum: natural + building's own lighting
- The building looks occupied and alive, never dark or unlit

INTERIOR LIGHTING: [if applicable]
- Natural window light consistent with established exterior time
- Premium feel: high ceilings, polished surfaces, clean lines

DO NOT:
- Generate any voice, narration, or dialogue beyond the provided
  audio file
- Add any text not listed in the VFX Text Overlay Instructions
- Add furniture, people, or objects not described in scene instructions
- Change time of day mid-clip — lighting stays consistent
- Make the character look different from the reference image
- Show the building with all lights off in any exterior shot
```

## 7. Fully Worked Example — Clip 1 of a Project Hero Film

This is a complete, filled-in example. The app should reference this as a "gold standard" of what a Seedance prompt looks like when done right.

### Scenario

- **Project:** Prestige North Woods (fictional — 3BHK apartment project)
- **Location:** Bellary Road, North Bengaluru
- **Video:** Project Hero Film
- **Clip:** Clip 1 — "Arrival"
- **Duration:** 8 seconds
- **Scenes:** 2 (aerial → ground entrance)
- **Character:** Not present (Hero Film opening clip establishes space before character appears in later clips)
- **Audio direction selected:** Option A — Voice + Ambient
- **Script:** *"Seven acres of green, just off Bellary Road. Welcome home."* (13 words, ~6.2s speech)

### The Filled Prompt

```
================================================================
CLIP 1 — ARRIVAL
Video: Project Hero Film — Prestige North Woods
Tool: Seedance 2.0
Format: 9:16 vertical, 1080×1920, 24fps
Duration: 8 seconds
Scenes: 2 (using 2 environment images)
Character: Not present
Audio: Provided — ElevenLabs, 6.2 seconds
================================================================

================================================================
INPUT DECLARATION
================================================================

No character reference. This clip is voiceover-only — no person
appears on screen.

ENVIRONMENT IMAGE 1 — AERIAL ESTABLISHING:
  Aerial view of Prestige North Woods at golden morning light —
  three residential towers rising from a dense landscaped campus,
  seven-acre green canopy visible, surrounding tree-lined
  boulevards, warm amber glow from tower windows, pink-gold sky.
  Used for: Scene 1 (0.0s–4.0s)

ENVIRONMENT IMAGE 2 — GROUND ENTRANCE:
  Ground-level view of the project entrance gateway at the same
  golden morning hour — granite-clad archway, landscaped driveway
  lined with palms, security cabin visible in soft focus to the
  side, warm interior glow from lobby visible through the arch,
  project name signage backlit in amber.
  Used for: Scene 2 (4.0s–8.0s)

AUDIO FILE:
  Pre-recorded voiceover, 6.2 seconds duration.
  This is the primary voice track. No character on screen — no lip
  sync required.
  Generate ambient environmental sound matching each scene.

================================================================
AUDIO HANDLING
================================================================

PRIMARY AUDIO: Use the provided audio file as the voiceover track
for this clip. No character on screen — no lip sync required.

AMBIENT GENERATION: Generate environmental ambient sound appropriate
to each scene:
- Scene 1 (aerial): High-altitude open air — distant urban hum far
  below, faint wind across treetops, soft bird calls carrying up
  from the canopy. The acoustic is wide, spacious, elevated — the
  feeling of looking down from above.
- Scene 2 (entrance): Ground-level morning — closer bird calls from
  the landscaped palms, soft footsteps on granite paving in the
  distance, gentle breeze through foliage, an occasional faint
  rustle of leaves. The acoustic narrows — we are inside the
  project now, not above it.

AMBIENT LEVEL: Ambient sits beneath the voice — felt, not heard.
The voiceover is always dominant.

DO NOT generate any additional voice, narration, dialogue, or
speech beyond the provided audio.
DO NOT generate background music.

================================================================
SCENE-BY-SCENE INSTRUCTIONS
================================================================

SCENE 1 (0.0s–4.0s) — AERIAL ESTABLISHING
  Environment: Use Environment Image 1
  Camera:
    Start: Bird's-eye view of the full campus from approximately
      150 metres altitude — all three towers in frame, canopy
      spreading below, horizon visible at the top third.
    Movement: Slow descending crane — the camera lowers gradually
      toward the campus, bringing the towers slightly closer and
      revealing more detail in the landscaping below.
    Speed: Barely perceptible descent — the camera covers
      approximately 15–20 metres of vertical drop across the full
      4 seconds. No rotation, no sideways drift.
    End: Still aerial but slightly closer — towers now dominate
      the upper two-thirds of frame, canopy detail clearer,
      individual tree crowns distinguishable.
  Character: Not visible in this scene.
  Ambient: High-altitude open air — distant city hum far below,
    faint wind across treetops, soft bird calls carrying up from
    the canopy. The acoustic is wide and elevated, the feeling of
    looking down from above.

--- TRANSITION: Hard cut at 4.0s ---

SCENE 2 (4.0s–8.0s) — GROUND ENTRANCE
  Environment: Use Environment Image 2
  Camera:
    Start: Ground-level frontal view of the granite entrance
      archway, positioned approximately 6 metres from the arch.
      The archway fills the upper two-thirds of the vertical
      frame. The driveway leads into the frame centre.
    Movement: Slow dolly-in — the camera moves forward toward the
      archway, approaching the entrance.
    Speed: Barely perceptible forward drift — the camera covers
      approximately 2 metres of forward travel across 4 seconds.
```

### What This Example Demonstrates

1. **Input declaration is explicit.** Every image is named, described in one line, and timestamp-assigned before the scene instructions reference it.
2. **Audio handling prohibits generation failures.** The `DO NOT generate additional voice` line prevents the most common Seedance failure.
3. **Scene timestamps align with the audio.** Scene 1 is 0.0–4.0s; the hard cut at 4.0s lands on a natural pause in the voiceover (between "Bellary Road" and "Welcome home").
4. **VFX text is dialogue-synced.** Each text entry is triggered by a specific word in the audio, not arbitrary timestamps.
5. **Final hold is calculated.** The last VFX text (the kicker) enters at 5.8s, giving it 2.2 seconds on screen before the clip ends — comfortable reading time.
6. **Quality directives target known failure modes.** The exterior lighting rule prevents the building from appearing unlit; the audio DO NOT prevents unwanted narration generation.

## 8. Scene Patterns Library

Use these patterns as starting points for the Stage 3 breakdown. Match the pattern to the video type, adapt to the project's available assets.

### Pattern A — Exterior Arrival → Amenity → Interior
Best for: Presenter Walkthrough clips, Hero Film opening sequences

| Scene | Environment | Camera | Character | Duration |
|---|---|---|---|---|
| 1 | Entrance / driveway | Slow dolly-in | Walking toward building, welcoming gesture | 3–3.5s |
| 2 | Key amenity (garden/pool/clubhouse) | Slow pan or glide-through | Walking through, pointing to features | 3–3.5s |
| 3 | Apartment interior | Glide-through or static hold | Standing inside, open-palm gesture | 2.5–3s |

Acoustic progression: Open exterior → semi-open amenity → enclosed interior

### Pattern B — Interior Walkthrough (Room to Room)
Best for: Interior Tour clips, no character

| Scene | Environment | Camera | Character | Duration |
|---|---|---|---|---|
| 1 | Living / drawing room | Slow glide-through from entrance | None | 3–4s |
| 2 | Kitchen / dining | Slow dolly-in | None | 3–3.5s |
| 3 | Balcony or bedroom | Slow dolly-in or static hold | None | 2.5–3s |

Acoustic progression: Room reverb → enclosed kitchen → open balcony or intimate bedroom

### Pattern C — Amenity Deep Dive (Two Angles)
Best for: Amenity Spotlight clips

| Scene | Environment | Camera | Character | Duration |
|---|---|---|---|---|
| 1 | Wide establishing of amenity | Slow dolly-in or static wide | Optional figure using amenity | 4–5s |
| 2 | Close detail or experience view | Slow dolly-in or slow orbit | Optional | 4–5s |

Acoustic progression: Open establishing → intimate detail

### Pattern D — Aerial → Ground Level
Best for: Hero Film establishing clips, Location Advantage

| Scene | Environment | Camera | Character | Duration |
|---|---|---|---|---|
| 1 | Aerial / bird's-eye view | Slow descending crane or static aerial | None | 4–5s |
| 2 | Ground level — entrance or street | Slow dolly-in | Optional | 4–5s |

Acoustic progression: High, wind-present, distant → ground level, close, detailed

### Pattern E — Character Direct Address (Single Scene)
Best for: Trust clips, CTA closes, brand closes

| Scene | Environment | Camera | Character | Duration |
|---|---|---|---|---|
| 1 | Exterior or branded setting | Slow push-in or static hold | Centre frame, direct to camera, speaking | 8–10s |

Acoustic progression: Single consistent acoustic throughout

### Pattern F — Lifestyle Moment (Single Scene)
Best for: Lifestyle Moment videos (no stitching)

| Scene | Environment | Camera | Character | Duration |
|---|---|---|---|---|
| 1 | One aspirational space (balcony, pool, garden, terrace) | Slow movement or static hold | Optional lifestyle figure (not presenter) | 8–15s |

Acoustic progression: Single consistent ambient — immersive, atmospheric

## 9. Camera Movement Vocabulary

Use these exact terms in scene instructions. Vague terms like "slow" are insufficient — always specify the rate.

| Movement | Description | Best For |
|---|---|---|
| Slow dolly-in | Camera moves forward toward subject | Approaching entrance, moving into room, closing on feature |
| Slow dolly-out / pull-back | Camera moves backward, reveals more | Revealing full building, opening wide view |
| Slow pan left/right | Camera rotates horizontally on fixed point | Scanning across amenity, following walking character |
| Rising crane | Camera moves upward vertically | Stairwell reveals, facade reveals, showing height |
| Descending crane | Camera moves downward vertically | Top-down reveals, arriving from above |
| Slow orbit | Camera moves in slight arc around subject | Character close-ups, feature spotlights, hero shots |
| Static hold | No camera movement | Price reveals, final brand frames, stillness moments |
| Glide-through | Camera floats forward through space at eye level | Interior walkthroughs, moving through rooms |

### Speed Specification Required

Every movement must include a concrete speed:
- **Bad:** "Slow dolly-in"
- **Good:** "Slow dolly-in. Barely perceptible forward drift — camera covers approximately 2 metres over 4 seconds."
- **Good:** "Slow descending crane — camera covers 15–20 metres of vertical drop across 4 seconds."

### One Movement Per Scene

Never combine movement types within a single scene. Dolly + pan + crane in one scene causes jerky motion and Seedance interpretation failures. One movement, one scene.

## 10. VFX Text Overlay Quick Reference

All VFX text is locked in Stage 3. The Seedance prompt carries forward every text element exactly as planned — no additions, no modifications.

### Element Types

| Style | Used For | Position | Animation |
|---|---|---|---|
| **Frosted pill chip** | Location, amenity, feature, floor/unit, room, distance, status tags | Lower or upper third, away from centre | Fade in 0.3–0.4s |
| **Floating data card** | Price, sqft, EMI, area, booking amount, unit count | Lower-left or lower-right, 55–70% from top, never centred | Slide in 0.5–0.6s from edge |
| **Bottom kicker** | Project name, emotional close, key tagline, CTA | Bottom 18–20%, centred, two ruled lines + scrim | **Snap in — instant** |
| **Location label (top)** | City, micro-market, area name | Top 10–12%, horizontally centred | Fade in 0.4s |
| **Split left/right chips** | Comparisons (2BHK vs 3BHK, Tower A vs B) | Equal counts left and right, stacked vertically | Sequential fade in |
| **Developer / brand bar** | Developer name + RERA (final clip only) | Bottom 5–8%, full width | Fade in 0.5s |
| **Offer badge** | Limited offers, stamp duty waivers, pre-launch pricing | Top-right corner, 10–15% from top, 5–8% from right | Slide in 0.4s from top-right |

### Density Rules

- **Maximum 4 text elements visible simultaneously** in any frame
- **Maximum 3 text elements entering** in any single scene
- Text never covers more than 30% of the frame
- One kicker per clip, maximum
- One location label per clip, maximum

### Timing Rules

- Text is **dialogue-synced** (not timer-based) when voiceover exists
- Entry description format: `"Appears on the word '[trigger word]' in the audio"`
- For ambient-only clips (Option C): entries are timer-based at specified seconds
- All elements persist from entry to end of clip (no mid-clip exits)
- Final hold (last 1.0–1.5s) shows **all text simultaneously**
- Kicker **always enters last** — final 2–3 seconds of clip

### Minimum On-Screen Time

| Element | Minimum Visible Time |
|---|---|
| Short chip (1–4 words) | 1.5 seconds |
| Medium chip (5–8 words) | 2.5 seconds |
| Data card | 2.0 seconds |
| Kicker (1–2 lines) | 2.0 seconds |

If the kicker enters at 7.0s in an 8.0s clip, visible time is only 1.0s — **insufficient**. Move entry earlier.

### Case and Language Rules

- All chips and kickers: **ALL CAPS**
- Numbers: Indian system — `₹85 LAKHS`, `₹1.2 CRORE` (not millions/billions)
- Currency: `₹` symbol before amount
- Square footage: `SQFT` (all caps, no period, no space)
- BHK: `2 BHK`, `3 BHK` (space, all caps)
- Price gets asterisk: `₹85 LAKHS*` — disclaimer in brand bar

### Safe Zones (Meta Reels / Stories)

- Top safe zone: below 12% from top
- Bottom safe zone: above 15% from bottom (except brand bar at 5–8%)
- Left safe zone: right of 5% from left edge
- Right safe zone: left of 5% from right edge
- Never place critical text in bottom 12% (except brand bar)

## 11. Quality Directives & Hard Rules

These rules appear in every Seedance prompt's Quality Directives section, tailored to the specific clip.

### Visual Quality
- Photorealistic, editorial quality
- No AI skin softening on character
- No warped hands, extra fingers, distorted faces
- Straight architectural lines, correct perspective
- No sky as flat colour fill — sky has depth

### Character Consistency (when present)
- Face, wardrobe, accessories, build must match reference image
- Skin tone consistent across all scenes
- Proportions natural
- Key features reinforced in text (wardrobe state, accessories, distinguishing features)

### Exterior Lighting (critical)
- Building architectural lights **always ON** — never show dark, unlit building
- Two light sources minimum: natural (sun/sky) + building's own lighting
- Windows glow warm amber
- Consistent light direction across clips sharing the same exterior

### Interior Lighting
- Natural window light matches established exterior time of day
- Premium feel: high ceilings, polished surfaces, clean lines
- For under-construction projects: render-style visualization, unfurnished unless explicitly described

### Camera Constraints
- All movement slow and deliberate
- Specific speed per scene (no vague "slow")
- One movement type per scene
- No sudden acceleration or deceleration

### Scene Changes
- Hard cuts only — no dissolves, wipes, fades, blends
- Each scene's starting frame is independent
- State explicitly: `"Hard cut at X.Xs"`
- Time of day stays consistent within a single clip

### Audio Rules
- Use ONLY the provided audio file for voice
- Generate ambient per scene from visual context
- No background music generation
- Ambient sits beneath voice — felt, not heard

### Universal DO NOTs (include in every prompt)
- Do not generate voice, narration, or dialogue beyond the provided audio
- Do not add text not listed in VFX Text Overlay Instructions
- Do not add people, furniture, or objects not described in scene instructions
- Do not change time of day mid-clip
- Do not make character look different from reference image
- Do not show building with all lights off in exterior shots
- Do not generate background music

## 12. Common Failures and Fixes

The app should check every generated prompt against this table before outputting.

| Failure | Cause | Fix |
|---|---|---|
| Seedance generates unwanted voice/narration | Audio handling missing, or standalone AUDIO section triggers generation | Include audio declaration in Audio Handling section: "Use provided audio only. DO NOT generate any additional voice." Remove any standalone AUDIO section. |
| Character doesn't match reference | Key features not reinforced in prompt | List 3–4 key features in Input Declaration AND repeat in Quality Directives. Be specific: "cobalt blue blazer, OPEN, never buttoned." |
| Scene change looks like blend/dissolve | Transition type not specified, or vague "transition" | Always say "Hard cut at [time]." Describe each scene's starting frame independently. |
| Camera movement too fast | Vague speed terms | Specify exact rate: "5–8% of frame depth" or "2 metres of forward travel over 4 seconds." |
| Character appears in wrong scene | Ambiguous presence instructions | State presence per scene: "Character visible in Scene 1 and Scene 2. Character NOT visible in Scene 3." |
| Interior looks AI-generated | Generic description | Add specific material callouts + "Unfurnished — no furniture, no staging. Architecture and natural light only. Photorealistic, editorial quality." |
| Ambient overwhelms voice | No level instruction | Add "Ambient sits beneath the voice — felt, not heard. Voice is always dominant." |
| Lighting changes between scenes | No consistency instruction | Add "Lighting remains consistent across all scenes — [time of day]. No mid-clip lighting changes." |
| Text appears that wasn't instructed | Seedance picked up text from environment image, or auto-generated captions | Ensure environment images have NO text baked in. Add "No text appears on screen except what is listed in VFX Text Overlay Instructions. No watermarks, no labels, no auto-generated captions." |
| Character lip sync off | Audio duration mismatch or sync timing not specified | Specify exact lip sync time range per scene: "Lip sync active from 0.3s to 3.8s in Scene 1." |
| Building looks dark / unlit | No lighting instruction for exterior | Add "Building exterior lights ON — architectural lighting visible, warm amber glow from windows. The building looks occupied and alive." |
| Character looks stiff or posed | Action described as position, not movement | Use natural action language: "Walking with a relaxed stride" not "Standing in position A." Add "Natural easy posture — not posed or stiff." |
| Unwanted background music | No music prohibition | Add "DO NOT generate background music" in Audio Handling. |
| Kicker fades instead of snapping | Animation type not specified correctly | Explicitly state "SNAP IN — instant, no transition. No fade, no slide." |
| Price data card appears too early | Entry timestamp before emotional setup | Move data card entry to after midpoint of clip. Never open with price. |

## 13. Prompt Generation Instructions for the Application

This section tells your LLM/app exactly how to assemble a Seedance prompt from upstream data.

### Inputs the App Must Have Before Prompt Generation

1. **Campaign-level data (from Stage 1):**
   - Project name, developer, location
   - Audio direction selection (A / B / C)
   - Presenter profile (if applicable)
   - Visual asset inventory

2. **Video-level data (from Stage 2):**
   - Video type (Hero Film / Walkthrough / Amenity / Interior / Location / Price / Trust / Lifestyle)
   - Complete voice script for this video

3. **Clip-level data (from Stage 3 breakdown):**
   - Clip title and duration
   - Scene plan (environment image per scene, camera, timestamps)
   - Audio sync plan (per segment)
   - VFX text plan (locked — strings, positions, animations, triggers)
   - Character action notes (if applicable)

4. **Generated audio:**
   - ElevenLabs audio file for this clip, with confirmed duration

### Prompt Assembly Algorithm

```
1. Start with Section 1 — HEADER
   Fill: clip number, title, video type, duration, scene count,
   character presence (from profile), audio presence (from Step 0
   selection)

2. Section 2 — INPUT DECLARATION
   IF character present:
     Output character block with 3–4 key features from profile
     Specify which scenes character appears in
   FOR each environment image (1 to N):
     Output image block with one-line description + timestamp range
   Output AUDIO FILE block with duration
   IF audio direction is Option C (ambient only):
     Replace AUDIO FILE block with "No voice audio file provided"

3. Section 3 — AUDIO HANDLING
   IF Option A or B:
     Output PRIMARY AUDIO line
     IF character speaks: output LIP SYNC block with per-scene time
       ranges
     Output AMBIENT GENERATION with per-scene ambient description
     Output AMBIENT LEVEL line
     Output DO NOT voice, DO NOT music
   IF Option C:
     No primary audio; ambient-only instruction
     Strong DO NOT voice emphasis

4. Section 4 — SCENE-BY-SCENE INSTRUCTIONS
   FOR each scene (1 to N):
     Output SCENE [N] header with timestamp range and scene name
     Output Environment: Use Environment Image [N]
     Output Camera block (start frame, movement, speed, end frame)
     IF character present in this scene:
       Output Character block (position, action, gesture, expression,
       lip sync time if speaking)
     ELSE:
       Output "Character: Not visible in this scene."
     Output Ambient block (scene-specific ambient, woven in)
   Between scenes: output "--- TRANSITION: Hard cut at [time] ---"

5. Section 5 — VFX TEXT OVERLAY INSTRUCTIONS
   Lead with: "All text below is FINAL — locked from Stage 3
     breakdown. No additional text appears."
   FOR each text element from Stage 3 VFX plan:
     Output TEXT [N] block with string, style, position, entry time,
     trigger, animation, scene, persistence
   Output FINAL HOLD TEXT STATE block listing all simultaneous text

6. Section 6 — FINAL HOLD
   Output timestamp range (from [last voice end + 0.x] to clip end)
   Output camera state (static / settling)
   Output character state (final pose or "Not visible")
   Output environment image reference
   Output text visible list
   Output ambient state (quietest)

7. Section 7 — QUALITY DIRECTIVES
   Always include:
     - Visual quality block
     - Camera block (with this clip's specific speed)
     - Scene changes block
     - Audio block
     - DO NOT list
   Conditionally include:
     - Character consistency (if character present — with key feature
       reinforcements from profile)
     - Exterior lighting (if any scene is exterior)
     - Interior lighting (if any scene is interior)

8. Final check: word count against target range. Trim if over 1,500.
```

### What the App Should NEVER Do

- Generate prompts before Stage 3 approval
- Add VFX text not in the Stage 3 plan
- Generate a prompt without an audio handling section
- Skip the DO NOT lines
- Use vague camera speed ("slow" without a rate)
- Combine multiple movements in a single scene
- Dissolve/fade between scenes — hard cuts only
- Show a building unlit in exterior shots
- Open any clip with a price reveal
- Mix the audio direction — if Option A was selected, don't add music references to the prompt

### Prompt Output Format

Return the prompt as plain text (not JSON, not markdown). The prompt goes into a text file the user uploads alongside the image and audio files to Seedance. Use the section divider `================================================================` exactly as shown in the template — Seedance parses visual structure.

## Appendix — Quick Reference Cheat Sheet

### The Three Audio Options
- **A:** Voice + Ambient (default, most video types)
- **B:** Voice + Ambient + Post-production Music (Hero Films)
- **C:** Ambient only + Text overlays (Lifestyle Moments)

### The Three Seedance Inputs
- Character reference image (optional per clip)
- Environment images (1–3 per clip)
- Audio file (if Option A or B)

### The Seven Prompt Sections
1. Header
2. Input Declaration
3. Audio Handling
4. Scene-by-Scene Instructions
5. VFX Text Overlay Instructions
6. Final Hold
7. Quality Directives

### Clip Duration Targets
- 8–10s sweet spot
- 15s maximum
- 1–3 scenes per clip
- 2.5–5s per scene in 8–10s clips

### Audio-to-Clip Buffer
- Audio ends 1.0–2.0s before clip ends
- Buffer = final hold (all text visible, camera settled)

### Hard Rules (Never Violate)
- Hard cuts only — no dissolves
- One camera movement per scene
- Building lights always ON in exteriors
- No voice generation beyond provided audio
- No music generation (post-production only)
- Kicker always snaps, never fades
- Kicker enters last
- Price never appears in Clip 1 of any video
- Text never added after Stage 3 lock
